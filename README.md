# 🧮 Calculadora IMC

**Calculadora IMC** es una aplicación móvil desarrollada en **Flutter** que permite calcular el **Índice de Masa Corporal (IMC)** de los usuarios a partir de su peso y altura, ofreciendo además una interpretación de la categoría correspondiente y una recomendación de salud personalizada.

---

## 🚀 Funcionalidades principales

- **Registro e inicio de sesión de usuarios** para acceder a su historial de cálculos.  
- **Cálculo de IMC** con soporte para dos sistemas de medida:
  - Sistema **métrico**: peso en kilogramos (kg) y altura en centímetros (cm).  
  - Sistema **imperial**: peso en libras (lb) y altura en pies (ft).  
- **Resultados detallados**, que incluyen:
  - Valor del IMC obtenido.  
  - Categoría correspondiente (bajo peso, normal, sobrepeso u obesidad).  
  - Recomendación general de salud.  
- **Modo invitado**, que permite realizar cálculos sin necesidad de registro, aunque sin guardar el historial.  
- **Historial de cálculos** accesible solo para usuarios registrados.

---

## 🧰 Tecnologías utilizadas

- **Framework:** Flutter  
- **Lenguaje:** Dart  
- **Base de datos:** Firebase Realtime Database  
- **Plataforma de despliegue:** Android (disponible mediante archivo APK)

---

## ⚙️ Instalación y ejecución

1. Descarga la aplicación en formato **APK** e instálala en tu dispositivo Android.  
2. Abre la app y elige una de las dos opciones disponibles:
   - **Iniciar sesión / Registrarse** para acceder al historial de cálculos.  
   - **Ingresar como invitado** para realizar cálculos sin guardar datos.  
3. Selecciona el sistema de medida (métrico o imperial).  
4. Ingresa tu peso y altura.  
5. Presiona **Calcular IMC** para obtener tu resultado y la recomendación de salud.  
6. Si iniciaste sesión, podrás **consultar el historial** de cálculos previos junto con su categoría de IMC correspondiente.
